## Chạy nhanh

```bash
npm ci
npm start
```

Mở `http://localhost:4200/`. Xem [hướng dẫn đầy đủ](Docs/README.md) cho test, build, assets, audio và GitHub Pages.

Tài liệu nằm trong `Docs/`; bằng chứng ảnh/video/JSON vẫn ở `qa/`, mã kiểm thử ở `scripts/qa/`, asset website ở `public/`. `README.md` này được giữ ở gốc làm trang giới thiệu GitHub.
