# PHẦN II. LỖI RUNTIME ĐÃ XÁC ĐỊNH CHÍNH XÁC

## 1. Thông báo lỗi thực tế

Tại:

http://localhost:4200/#memories

DevTools Console liên tục báo:

ERROR TypeError: Cannot read properties of undefined (reading 'length')

at InteractivePhotoGalleryComponent_Template

interactive-photo-gallery.html:73:72

Lỗi xuất hiện lặp lại nhiều lần trong quá trình Angular render.

Đây là lỗi runtime nghiêm trọng, có thể khiến quá trình rendering của gallery bị gián đoạn.

## 2. Nguyên nhân đã được xác định từ source code

Trong file:

src/app/components/interactive-photo-gallery/interactive-photo-gallery.ts

Input photos hiện tại được định nghĩa thông qua setter:

```typescript
@Input({ required: true })
set photos(value: readonly Photo[]) {
  this.photosSource.set(
    [...value].sort((left, right) => left.order - right.order)
  );
  this.syncAutoMotion();
}
```

Đây là setter dùng để đưa danh sách ảnh vào private signal.

Nó không phải getter có thể đọc trực tiếp.

Tuy nhiên, HTML template đang truy cập:

```html
{{ activePhotoNumber() }} / {{ photos.length }}
```

Và:

```html
[attr.aria-setsize]="photos.length"
```

Do không tồn tại getter `photos`, Angular nhận giá trị undefined tại runtime.

Khi truy cập `.length`, template phát sinh TypeError.

### Yêu cầu sửa

Phải sửa toàn bộ trường hợp template đang đọc `photos.length` không hợp lệ.

Ưu tiên tạo một computed signal public hoặc readonly:

```typescript
readonly photoCount = computed(
  () => this.photosSource().length
);
```

Sau đó thay các vị trí sử dụng không hợp lệ trong template thành:

```html
{{ activePhotoNumber() }} / {{ photoCount() }}
```

Và:

```html
[attr.aria-setsize]="photoCount()"
```

Không được chỉ sửa một vị trí rồi bỏ sót những vị trí khác.

### Yêu cầu bổ sung

Kiểm tra toàn bộ Angular template để tìm:

- Input setter bị đọc như getter.
- Thuộc tính không tồn tại.
- Signal được đọc sai cách.
- Computed signal được sử dụng sai.
- Truy cập thuộc tính của undefined/null.
- Binding có thể gây TypeError.
- Những lỗi template khác bị che khuất bởi exception hiện tại.

Không chỉ xử lý triệu chứng bằng optional chaining nếu bản chất là kiến trúc binding sai.

Phải sửa đúng nguồn dữ liệu.

- Hover rồi click.

- Kéo khi auto motion đang chạy.
- Rời chuột sau khi drag.
- Mở Lightbox rồi đóng.
- Chuyển sang tab khác.
- Gallery rời viewport.
- Resize trình duyệt.
- Bật reduced motion.
- Destroy component.

Kiểm tra đặc biệt logic pause/resume hiện tại.

Không cho phép nhiều GSAP tweens cùng ghi vào một thuộc tính position và gây xung đột.
